# Lead Engine + Delivery Factory canary v1

Release branch: `release/lead-engine-canary-v1`  
Base: `origin/feat/product-platform-design@dfece3b`

## Six-step implementation ledger

1. **CI and release controls** — root regression covers both products; both product UIs build in CI; release branches run CI; static and opt-in live readiness workflows are available.
2. **Branch hygiene** — release work is isolated from the older dirty workspace and remains a direct descendant of the verified remote feature base.
3. **Lead Engine durability** — persistent source reservations, daily/monthly budgets, cross-worker pacing, lease fencing, retention pruning, retry/DLQ, dedupe, and expanded audit coverage.
4. **Scoring and canary** — scoring v2.1 derives ICP fit from explicit industry/employee evidence; the owned deterministic fixture supplies permitted evidence and Toronto coordinates.
5. **Delivery Factory independence** — schema 1.1 audit stream, fail-closed readiness, independent Sentry/Vercel telemetry, and combined product readiness UI.
6. **Business loop** — Postman captures the opportunity ID, records human acceptance, and enqueues the signed, versioned Delivery Factory handoff.
