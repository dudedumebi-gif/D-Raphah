# D-Raphah

Raphah.io is an evidence-led AI and business-systems advisory practice for
founder-led teams doing complicated work.

## Repository layout

- `website/` — the public Raphah.io client website and consultation entry point.
- `lead-engine/` — reserved for the internal, compliance-first opportunity
  discovery and revenue pipeline.
- `delivery-tool/` — reserved for client delivery workflows, blueprints,
  implementation plans, and continuous-improvement reporting.

The current website build is generated from the Raphah.io app in
`artifacts/raphah-site/` and is published here as a static production bundle
under `website/`.

## Product boundaries

The public website does not expose internal lead records, source policies, or
outreach workflows. The Lead Engine remains human-reviewed, evidence-led, and
privacy-aware. Engagements are shaped around each client's context rather than
presented as fixed packages.
